# GitPractice

A dedicated sandbox repository for practicing Git commands, branching models, and version control workflows.

---

## 📌 Purpose

- Practice common Git CLI workflows (`clone`, `branch`, `commit`, `merge`, `rebase`, `stash`).
- Test remote repository operations and GitHub integration.
- Experiment with repository hooks and CI configurations safely.

---

## 🛠️ Usage

Clone this repository to experiment with version control scenarios:

```bash
git clone https://github.com/hanzlaahmadcheema/GitPractice.git
cd GitPractice
```
